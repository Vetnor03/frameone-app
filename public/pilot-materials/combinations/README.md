# RE:MIND real pilot frame photographs

Upload all **15 transparent PNG images** into this folder. Keep the original pixels, framing, transparent background, proportions and RE:MIND logo unchanged. Filenames are **case-sensitive**.

| Frame | Beige | Grey | Red | Green | Black |
| --- | --- | --- | --- | --- | --- |
| Oak | `OakBeige.png` | `OakGrey.png` | `OakRed.png` | `OakGreen.png` | `OakBlack.png` |
| Walnut | `WalnutBeige.png` | `WalnutGrey.png` | `WalnutRed.png` | `WalnutGreen.png` | `WalnutBlack.png` |
| Char | `CharBeige.png` | `CharGrey.png` | `CharRed.png` | `CharGreen.png` | `CharBlack.png` |

The preview in `app/pilot/PilotConfigurator.tsx` loads these files through `app/lib/pilotCombinationPhotos.ts`. If a file is not uploaded yet, the old illustrative preview is displayed instead.
